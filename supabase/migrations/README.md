# Supabase Migrations

هذا المجلد هو المكان الإلزامي والوحيد لجميع تغييرات قاعدة البيانات بدءًا من المرحلة 1.

## القواعد الإلزامية
1. كل تغيير في الجداول أو الفهارس أو الدوال أو سياسات RLS يتم عبر ملف migration مرقّم وموصوف بوضوح.
2. يُمنع تعديل ملف migration سبق تطبيقه على بيئة مشتركة؛ عند الحاجة للتعديل يُنشأ ملف migration جديد.
3. يُمنع تنفيذ SQL عشوائي مباشرة على قاعدة بيانات الإنتاج.
4. في المرحلة 0 لا توجد ملفات migration فعلية بعد.
