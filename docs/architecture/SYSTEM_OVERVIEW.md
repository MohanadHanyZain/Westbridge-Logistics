# النظرة المعمارية العامة للنظام (System Overview)

## 1. الرؤية والتطبيقات الخمسة
منصة SaaS متعددة الشركات (Multi-Tenant) لإدارة شركات الشحن والتوصيل، تعمل عبر 5 واجهات مترابطة ضمن عزل صارم لكل شركة (`tenant_id`):

1. **المنصة المركزية (Platform Console):** إنشاء الشركات وإدارتها، الباقات والحدود، النطاقات، ودخول الدعم المسبب والمراقب.
2. **موقع الشركة العام (Public Tenant Site):** صفحات الشركة، الخدمات والتغطية، التتبع العام المحدود للشحنة، وبوابة تسجيل العملاء (حسب إعداد التفعيل).
3. **لوحة إدارة الشركة (Admin / Operations Dashboard):** التعريفات الأساسية، الفروع والجغرافيا، العملاء وقوائم الأسعار، الأمان والصلاحيات، المندوبون وخطوط السير، الشحنات، قوائم التشغيل اليومية، العمليات المالية، المحاسبة العامة، التقارير، الإعدادات، وسجل التدقيق.
4. **بوابة العميل (Client Portal):** لوحة المؤشرات، إنشاء الشحنات، الاستيراد من Excel، طلبات الالتقاط، التتبع وطباعة البوالص، كشف الحساب والتسويات، المراسلات، ورموز API.
5. **بوابة المندوب (Courier Portal):** مهام اليوم، الخرائط والمحطات، التسليم والتعذر والإرجاع، إثبات التسليم والتوقيع، ملخص العهدة النقدية والشحنات، والمراسلات.

## 2. البنية التقنية المعتمدة
- **الواجهة الأمامية:** React 19 + TypeScript + Vite + Tailwind CSS v4 (واجهة عربية RTL).
- **الخدمات الخلفية وقاعدة البيانات:** Supabase PostgreSQL + Supabase Auth + Row Level Security (RLS) + Supabase Storage + Edge Functions / PostgreSQL RPC Functions.
- **الخرائط:** Google Maps Platform APIs (مقيدة في الواجهة بالـ referrer، مع عدم تسريب أي مفاتيح خادم).

## 3. المبادئ الأمنية والبياناتية
- **العزل متعدد الشركات:** كل سجل يخص شركة يحمل `tenant_id` إلزاميًا مع مفاتيح خارجية مركبة تمنع ربط سجلات بين شركتين، وسياسات RLS فعالة على كل جدول مكشوف.
- **منع الثغرات الشائعة:** لا يُستخدم `user_metadata` للتفويض، ولا تُخزن كلمات المرور في جداول التطبيق، ولا يُوضع `service_role` في React.
- **سلامة العمليات المالية والتشغيلية:** انتقالات حالة الشحنة وقوائم التشغيل واعتماد السندات والقيود تتم خادميًا داخل معاملات ذرية وبمفاتيح `idempotency_keys`، مع استخدام المستندات العكسية (`reversal`) بدل الحذف.
- **النطاقات والمسارات:** استخدام المسار `/c/:companySlug` في المراحل الأولى لحين تفعيل النطاقات الفرعية والمخصصة في المرحلة 15.
